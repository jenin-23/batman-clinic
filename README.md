# Batman Clinic — Vet Simulator

A 3D veterinary clinic simulation (dogs, cats, birds) with scientifically accurate exam, anaesthesia, aseptic prep and surgery steps.

**Play:** open `index.html` on any static host (GitHub Pages, Netlify, etc.). No account needed; progress is saved in the browser's local storage on the player's own device.

Built with Three.js (loaded from cdnjs).
